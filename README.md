# Week 4 - Exploratory Data Analysis

EDA of the [VC Deal Flow Signal](https://huggingface.co/datasets/the-data-nerd/vc-deal-flow-signal) dataset
(from the finance section of [Awesome Public Datasets](https://github.com/awesomedata/awesome-public-datasets#finance)).

- `eda_vc_deal_flow.ipynb` - the notebook
- `data/startup_signals.csv` - the data (219 rows, 13 columns)

To run:

```
pip install -r requirements.txt
jupyter notebook eda_vc_deal_flow.ipynb
```
